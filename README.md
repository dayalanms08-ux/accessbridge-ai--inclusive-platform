# AccessBridge AI

A responsive React + TypeScript prototype for an inclusive technology platform. It prioritizes three demonstrable workflows: learning notes and quizzes, accessibility settings with browser text-to-speech, and a resume builder. It also includes healthcare information guidance, medication reminders, digital literacy lessons, voice commands, saved resources, and a local activity dashboard.

## Requirements

- Node.js 20 or newer (LTS recommended)
- npm
- VS Code (recommended)

## Run locally

1. Extract `accessbridge-ai.zip`.
2. Open the extracted `accessbridge-ai` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed in the terminal (typically `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.

## AI integration

The default project runs in **local demo mode**. The lesson summary and quiz fallback are deliberately labelled as a demo; they are not a live AI model.

To connect a real AI service:

1. Create a backend endpoint that accepts a JSON body like:
   `{ "text": "...", "language": "en", "simpleLanguage": true }`
2. Return JSON with an `explanation` string and optional `quiz` array:
   ```json
   {
     "explanation": "A simplified explanation...",
     "quiz": [
       {
         "question": "Example question?",
         "options": ["A", "B", "C", "D"],
         "answer": 0,
         "explanation": "Why this answer is correct."
       }
     ]
   }
   ```
3. Copy `.env.example` to `.env` and set `VITE_AI_API_URL` to the backend endpoint.
4. Restart `npm run dev`.

**Security:** Never place private AI provider keys in frontend environment variables or browser code. The backend should hold secrets, validate requests, limit upload sizes, and apply rate limits. Configure CORS for the frontend origin.

## Implemented features

- Responsive dashboard and sidebar navigation.
- Accessibility preferences: large text, high contrast, dark mode, simple-language toggle, English/Tamil selection, and low-data mode.
- Browser text-to-speech when supported.
- Browser speech recognition when supported and permission is granted; typed commands remain available.
- Notes input and upload for `.txt`, `.md`, and `.csv` files (maximum 1 MB).
- Local demo lesson summary and practice quiz; optional backend endpoint for real AI output.
- Resume form with live preview and `.txt` download.
- Healthcare appointment preparation guidance and locally saved reminders.
- Digital literacy step-by-step guides.
- Saved resources and local activity counters using browser local storage.
- Downloadable saved resources and clear-local-data action.
- Input validation and accessible status messages.

## Known limitations

- No user accounts, cloud database, or cross-device synchronisation.
- Tamil support is partial in this prototype; some interface labels remain in English.
- The local demo summary and quiz are not generated by a language model.
- Speech recognition support varies by browser; Chrome-based browsers often provide broader support. Text-to-speech depends on installed browser voices.
- Reminder entries are stored, but this prototype does not send push notifications or trigger alarms.
- Hospital lookup is not geolocation-enabled; the official portal link is provided as a starting point. Verify facilities and services directly.
- Uploading PDF and DOCX files is not implemented; only plain text formats are supported.
- Offline resource caching/PWA installation is not configured in this starter version.
- Resume export is plain text; open it in a word processor to style it and export as PDF.
- The healthcare content is general guidance and not medical diagnosis or treatment advice.

## Accessibility checks to perform

- Navigate all controls with Tab, Shift+Tab, Enter, and Space.
- Confirm visible focus indicators and skip-to-content link.
- Test at 200% browser zoom and on a narrow mobile viewport.
- Test high contrast and dark mode.
- Test with a screen reader.
- Confirm microphone permission denial has a usable typed-command alternative.
- Verify form labels and validation messages.
- Test Tamil display and available speech voices on the target device.

## Data and privacy

Saved resources, preferences, reminders, and usage counters are stored in this browser's local storage. They are not encrypted or synced. Do not enter sensitive health information or private personal data in this prototype. Use the Settings page to clear local activity data.
